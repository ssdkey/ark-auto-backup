## 三、生成安装向导 Setup.exe（需 Inno Setup）

### 步骤
1. 下载并安装 **Inno Setup 6**（免费）：https://jrsoftware.org/isdl.php
2. 双击 `build_all.bat`
3. 脚本会自动：先用 PyInstaller 生成单文件 exe → 再调用 `ISCC.exe` 编译 `installer.iss`

产出：`dist\方舟自动备份工具_Setup.exe`

`installer.iss` 已配置好：
- 中文安装向导、现代风格
- 默认安装到 `Program Files\方舟自动备份工具`
- 可选创建桌面快捷方式
- 开始菜单快捷方式 + 卸载入口
- `lzma2/max` 极限压缩，安装包体积最小
- 安装完成后可选立即运行

## 四、生成 MSI 安装包（需 WiX 或 Visual Studio）

MSI 适合 IT 部门批量分发。两种方式：

### 方式 A：WiX Toolset（推荐，免费、命令行）
1. 安装 **WiX Toolset v3**（含 candle/light 编译工具）：https://wixtoolset.org/
2. 在项目根目录新建 `wix_setup.wxs`（内容见 `docs\wix_setup.wxs`）
3. 命令行编译：
   ```bat
   candle.exe wix_setup.wxs
   light.exe wix_setup.wixobj -o dist\方舟自动备份工具.msi -b dist
   ```
4. 产出：`dist\方舟自动备份工具.msi`

### 方式 B：Visual Studio Installer 项目
1. 在 VS 中新建「Setup Project」→ 将 `dist\方舟自动备份工具.exe` 加入主输出
2. 配置 ProductName / 快捷方式
3. 生成即得 `.msi`

> 注意：MSI 安装的是免安装 exe 的打包分发版本，程序本体仍为单文件 exe。
